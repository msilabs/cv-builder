# CVবানাও — ডেভেলপারদের জন্য CV, GitHub README ও পোর্টফোলিও বিল্ডার

[![CI](https://github.com/msilabs/msilabs-cv-builder/actions/workflows/ci.yml/badge.svg)](https://github.com/msilabs/msilabs-cv-builder/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-teal.svg)](LICENSE)

বাংলাদেশের ওয়েব, মোবাইল আর সফটওয়্যার ডেভেলপারদের জন্য একটা ফ্রি, ওপেন সোর্স টুল। একবার তথ্য দিলেই তৈরি হয়:
- ATS-বান্ধব **CV (PDF)**
- **GitHub প্রোফাইল README**
- এক পাতার **পোর্টফোলিও ওয়েবসাইট**

কোনো লগইন বা সার্ভার নেই। সব তথ্য শুধু আপনার ব্রাউজারে থাকে।

🔗 **লাইভ:** https://msilabs-cv-builder.vercel.app · [English](https://msilabs-cv-builder.vercel.app/en/)

## ফিচার

**CV**
- **৬টা টেমপ্লেট:**
  - ATS-বান্ধব: ক্লাসিক, কম্প্যাক্ট, এলিগ্যান্ট
  - ডিজাইন: মডার্ন, টাইমলাইন, মিনিমাল
- লাইভ A4 প্রিভিউ, জুম করা যায়। পছন্দের রং আর ঐচ্ছিক ছবি।
- PDF-এর লেখা সিলেক্ট করা যায়, ATS পড়তে পারে। ফোনে PDF সেভ করার নির্দেশনাও দেখায়।
- বাংলাদেশি ফরম্যাট: CGPA/৪.০০, SSC/HSC GPA/৫.০০, +880, ICPC/Codeforces।
- CV কতটা তৈরি তার মিটার, সাথে পরের কাজের পরামর্শ।

**GitHub README**
- ৪টা স্টাইল: ক্লাসিক, সেন্টার্ড, কোড, মিনিমাল।
- স্কিল থেকে নিজে থেকে টেক ব্যাজ আর আইকন। চাইলে GitHub stats।
- প্রিভিউ দেখা, Markdown কপি বা README.md ডাউনলোড।

**পোর্টফোলিও**
- ৩টা থিম: ক্লিন (নিজে থেকে ডার্ক মোড), মিডনাইট, বেন্টো।
- একটাই `index.html` ফাইল, GitHub Pages বা Netlify-তে সরাসরি বসানো যায়।
- ফোন নম্বর শুরু থেকেই লুকানো। সব লেখা escape করা, তাই কেউ স্ক্রিপ্ট ঢোকাতে পারে না।

**AI সহায়তা (API key ছাড়াই)**
- প্রম্পট কপি করে ChatGPT, Claude বা Gemini-তে দিন, তারপর উত্তর এখানে পেস্ট করুন।
- পাঁচটা কাজ করা যায়: পুরোনো CV থেকে শুরু, লেখা ভালো করা, নির্দিষ্ট চাকরির জন্য সাজানো, পরিচিতি লেখা, কভার লেটার।
- বসানোর আগে কী বদলাবে তার তালিকা দেখায়। AI নতুন সংখ্যা বানালে সতর্ক করে। এক ক্লিকে আগের অবস্থায় ফেরা যায়।
- ফোন, ইমেইল আর ছবি কখনো AI-কে পাঠানো হয় না।

**ডেটা ও ব্যবহার**
- **একাধিক CV ভার্সন:** যেমন একটা মূল CV, আর নির্দিষ্ট কোম্পানির জন্য আলাদা CV।
- **অটো-সেভ আর ট্যাব sync:** তথ্য নিজে থেকে সেভ হয়। একাধিক ট্যাবে খোলা থাকলে প্রতিটা ভার্সনের সবচেয়ে নতুন কপি থাকে।
- **ব্যাকআপ:** ভার্সন নম্বরসহ JSON ফাইলে ব্যাকআপ নেওয়া আর আবার খোলা যায়। AI-এর উত্তরও সরাসরি খোলা যায়।
- **ছবি ছোট করা:** আপলোড করা ছবি নিজে থেকে ৪০০px-এ ছোট হয়, যাতে ব্রাউজারের জায়গা না ভরে।
- **দেখানো/লুকানো:** প্রতিটা সেকশন CV, README আর পোর্টফোলিওর জন্য আলাদাভাবে লুকানো যায়।
- **দুই ভাষা:** বাংলা আর English। বাংলাদেশ থেকে খুললে নিজে থেকে বাংলা আসে।
- **কিবোর্ড আর স্ক্রিন রিডার:** সব কাজ কিবোর্ড দিয়ে করা যায়, স্ক্রিন রিডারও ঠিকমতো কাজ করে (WCAG AA)।

## চালানো

```bash
npm install
npm run dev
```

তারপর http://localhost:3000 খুলুন।

| কমান্ড | কাজ |
|---|---|
| `npm run dev` | লোকাল ডেভেলপমেন্ট সার্ভার চালু করে |
| `npm run build` | পুরো সাইট static ফাইল হিসেবে `out/` ফোল্ডারে তৈরি করে |
| `npm start` | `out/` থেকে সাইটটা চালায় |
| `npm run lint` | ESLint দিয়ে কোড যাচাই করে |
| `npm run typecheck` | TypeScript-এর টাইপ পরীক্ষা করে |
| `npm test` | ইউনিট টেস্ট চালায় (Vitest) |
| `npm run test:e2e` | ব্রাউজারে e2e আর অ্যাক্সেসিবিলিটি টেস্ট চালায় (Playwright + axe)। আগে `npm run build` লাগে |
| `npm run check` | lint, typecheck আর ইউনিট টেস্ট একসাথে চালায় |
| `npm run previews` | হোম পেজের প্রিভিউ ছবি নতুন করে তৈরি করে। আগে `npm run build` লাগে |

প্রথমবার e2e টেস্ট চালানোর আগে ব্রাউজার ইনস্টল করে নিন: `npx playwright install chromium`

## ডিপ্লয়

- **Vercel:** repo import করলেই চলে, আলাদা কোনো সেটিং লাগে না।
- **GitHub Pages:** repo-র Settings → Pages → Source থেকে **GitHub Actions** বাছাই করুন। এরপর `main`-এ প্রতিটা push-এ `.github/workflows/pages.yml` নিজে থেকে সাইট বানিয়ে প্রকাশ করবে।
- **CI:** `.github/workflows/ci.yml` প্রতিটা push আর pull request-এ lint, typecheck, ইউনিট টেস্ট, build আর e2e টেস্ট চালায়।

## কাঠামো

```
src/
├── app/                  পেজ: হোম (/), English (/en), বিল্ডার (/builder), sitemap, robots
├── assets/previews/      হোম পেজের প্রিভিউ ছবি (npm run previews)
├── components/
│   ├── builder/          টুলবার, ভার্সন, ফাইল মেনু, এক্সপোর্ট, সতর্কবার্তা, অগ্রগতি
│   ├── editor/           ফর্ম আর ফর্মের অংশ
│   ├── templates/        CV টেমপ্লেট (নতুন টেমপ্লেট এখানে যোগ করে index.ts আর lib/templateMeta.ts-এ রেজিস্টার করুন)
│   ├── readme/ portfolio/ ai/   প্রতিটা ট্যাবের প্যানেল
│   ├── home/             হোম পেজ
│   └── ui/               ডায়ালগ, টোস্ট, Modal, Error Boundary, বোতামের স্টাইল
├── i18n/                 বাংলা ও ইংরেজি অভিধান (টাইপ করা), ভাষা চেনা
└── lib/                  স্টোর, ট্যাব মেলানো, ইমপোর্ট, README/পোর্টফোলিও/AI জেনারেটর, ছবি ছোট করা
tests/
├── unit/                 Vitest
└── e2e/                  Playwright + axe
```

## প্রাইভেসি

- কোনো সার্ভার, ডেটাবেস, ট্র্যাকিং বা analytics নেই।
- সব তথ্য ব্রাউজারের `localStorage`-এ থাকে।
- README-র ব্যাজ আর আইকন বাইরের সার্ভিস থেকে আসে (`img.shields.io`, `skillicons.dev`)। এগুলো শুধু আপনি যখন GitHub-এ README ব্যবহার করেন তখন লোড হয়। "মিনিমাল" স্টাইলে কোনো বাইরের ছবি নেই।
