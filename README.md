# CVবানাও — বাংলাদেশি ডেভেলপারদের জন্য CV, README ও পোর্টফোলিও বিল্ডার

ওয়েব, মোবাইল অ্যাপ ও সফটওয়্যার ডেভেলপারদের জন্য একটা ফ্রি টুল। একবার তথ্য দিলেই তিনটা জিনিস তৈরি হয়: ATS-বান্ধব **CV (PDF)**, **GitHub প্রোফাইল README**, আর এক পৃষ্ঠার **পোর্টফোলিও ওয়েবসাইট**।

🔗 লাইভ: https://msilabs-cv-builder.vercel.app

## ফিচার

**CV**
- ৬টা টেমপ্লেট: ক্লাসিক, কম্প্যাক্ট, এলিগ্যান্ট (ATS নিরাপদ), মডার্ন, টাইমলাইন, মিনিমাল (ডিজাইন), থাম্বনেইল দেখে বাছাই
- লাইভ A4 প্রিভিউ, পছন্দের রং, ঐচ্ছিক ছবি
- PDF ডাউনলোড (লেখা সিলেক্ট করা যায়, ATS পড়তে পারে)
- বাংলাদেশি ফরম্যাট: CGPA/৪.০০, SSC/HSC GPA/৫.০০, +880

**GitHub README**
- ৪টা স্টাইল: ক্লাসিক, সেন্টার্ড, কোড, মিনিমাল
- স্কিল থেকে নিজে থেকে টেক ব্যাজ ও আইকন, ঐচ্ছিক GitHub stats
- রেন্ডার করা প্রিভিউ, Markdown কপি বা README.md ডাউনলোড

**পোর্টফোলিও**
- ৩টা থিম: ক্লিন (নিজে থেকে ডার্ক মোড), মিডনাইট, বেন্টো
- একটাই `index.html` ফাইল, GitHub Pages বা Netlify-তে সরাসরি বসানো যায়
- ডেস্কটপ/মোবাইল প্রিভিউ, SEO ও Open Graph ট্যাগ
- ফোন নম্বর ডিফল্টভাবে লুকানো

**AI সহায়তা (API key ছাড়া)**
- প্রম্পট কপি করে ChatGPT/Claude/Gemini-তে দিন, উত্তর পেস্ট করুন
- পুরোনো CV থেকে শুরু, লেখা উন্নত করা, নির্দিষ্ট জবের জন্য সাজানো, সামারি, কভার লেটার
- কী বদলাবে তার তালিকা, AI নতুন সংখ্যা বানালে সতর্কবার্তা, এক ক্লিকে আগের অবস্থায় ফেরা
- ফোন, ইমেইল আর ছবি কখনো AI-কে পাঠানো হয় না

**ডেটা**
- একাধিক CV ভার্সন (যেমন মূল CV, নির্দিষ্ট কোম্পানির জন্য CV)
- ব্রাউজারে অটো-সেভ, একাধিক ট্যাবের মধ্যে sync, রিলোডে মুছে যায় না
- ভার্সন নম্বর সহ JSON ব্যাকআপ ও ইমপোর্ট
- প্রতিটা সেকশন CV, README ও পোর্টফোলিওর জন্য আলাদাভাবে দেখানো/লুকানো
- কোনো সার্ভার বা লগইন নেই, ডেটা শুধু আপনার ব্রাউজারে

## চালানো

```bash
npm install
npm run dev
```

তারপর http://localhost:3000 খুলুন। `npm run build` করলে পুরো সাইট static ফাইল হিসেবে `out/` ফোল্ডারে তৈরি হয়।

## ডিপ্লয়

- **Vercel:** repo import করলেই চলে, আলাদা কোনো সেটিং লাগে না।
- **GitHub Pages:** repo-র Settings → Pages → Source থেকে **GitHub Actions** বাছাই করুন। এরপর `main`-এ প্রতিটা push-এ `.github/workflows/pages.yml` নিজে থেকে সাইট বানিয়ে প্রকাশ করবে।

## কাঠামো

- `src/app/` — ল্যান্ডিং পেজ ও বিল্ডার
- `src/components/templates/` — CV টেমপ্লেট (নতুন টেমপ্লেট এখানে যোগ করে `index.ts`-এ রেজিস্টার করুন)
- `src/components/{editor,builder,readme,portfolio,ai}/` — ফর্ম, টুলবার ও প্রতিটা ট্যাবের অংশ
- `src/lib/store.tsx` — ডেটা স্টোর, ভার্সন, অটো-সেভ, ট্যাব sync
- `src/lib/readme.ts`, `src/lib/portfolio.ts`, `src/lib/ai.ts` — README, পোর্টফোলিও ও AI প্রম্পট জেনারেটর
- `src/lib/normalize.ts` — JSON ইমপোর্ট (পুরোনো ফাইল ও AI-এর উত্তর সামলায়)
